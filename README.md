# Global AI Students Project

Flask-based recreation of the web integration demonstrated in the supplied video.

## Features
- Global AI Students landing page
- HOME / DASHBOARD 1 / DASHBOARD 2 / STORY navigation
- Tableau Public Dashboard 1 embedded in the page
- Tableau Public Dashboard 2 embedded in the page
- Tableau Public Project Story embedded in the page
- Responsive Bootstrap layout
- Flask contact and newsletter demo routes

## Run

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000/
